Rink location test

Measuring distance to the rink (SIHF rink point ).

Before you start

  • iPhone: Settings → Privacy & Security → Location Services → Safari Websites → While Using, and Precise Location on. Then note whether it was on or off below.
  • Android: allow location for the browser and keep "Use precise location" on.
  • Do one measurement per seat. Several seats and both networks (Wi-Fi and mobile data) help most.
